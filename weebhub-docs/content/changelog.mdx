## [#](#v38)v3.8

### [#](#ui-and-performance-improvements)UI and Performance Improvements

![Page](https://WeebHub.app/bucket/guides/viewtransitions2.gif)

*   WeebHub Denshi now uses **native View Transitions** for smoother navigation and a more polished feel.
*   **Animations** have also been updated across the app to be more consistent in speed and feel snapper.
*   **Media entry headers** have been slightly redesigned to be more compact and less visually noisy.
*   **Route preloading** is now enabled by default and configurable in the settings.
*   Various optimizations have been made to increase **loading speed** for media pages. In addition to that, route preloading will make navigating to some media pages feel almost instant.

### [#](#improved-torrent-search)Improved Torrent Search

![Page](https://WeebHub.app/bucket/guides/img-20260507-184439-shrxde5h--sq.webp)

Torrent search can now query many providers at once, which makes it easier to compare results without having to switch between providers manually. This should make discovery faster, especially when availability differs across providers.

### [#](#updated-subtitle-translator)Updated Subtitle Translator

![Page](https://WeebHub.app/bucket/guides/img-20260507-185410-UX54XQ2o.png)

The subtitle translator now supports OpenAI-compatible local LLMs, making it possible to use self-hosted models instead of relying only on remote services. Language selection has also been fixed so translation setup behaves more consistently.

VideoCore (the in-app video player) will also now automatically import local subtitle files from the same directory as the video file. For external player links, a new `{subtitleUrl}` placeholder has been added to make passing local subtitle files easier.

### [#](#denshi-window-state)Denshi Window State

WeebHub Denshi now remembers window position and size between sessions, so the app reopens where you left it.

### [#](#hide-anime-spoilers)Hide Anime Spoilers

![Page](https://WeebHub.app/bucket/guides/img-20260507-170104-3jvf6k0b--sq.webp)

The 'Hide Anime Spoilers' plugin has been implemented natively for better performance. This will hide episode titles, descriptions, and thumbnails until you watch the episode. There is also a new `/spoilers` command in the Command Palette that lets you toggle spoilers on or off for an individual title for convenience.

### [#](#extension-improvements)Extension Improvements

![Page](https://WeebHub.app/bucket/guides/img-20260507-170340-gjkj3Wha.png)

Many improvements have been made to the extension system, including more APIs for deeper integrations and better security controls. Extensions can now be **disabled** directly, which is useful when you need to quickly disable a misbehaving extension without uninstalling it.

Plugins also gained more APIs, including `ctx.settings` to securely manage app settings, `ctx.auth` to securely manage authentication, and `ctx.extensions` to securely manage other extensions. To complement that, there is a new **Extension Secure Mode** setting that shows a prompt when an extension attempts a sensitive action.

### [#](#online-streaming-improvements)Online Streaming Improvements

![Page](https://WeebHub.app/bucket/guides/onlinestreamcycling.gif)

Online streaming now uses a new HTTP/1-based video proxy, which helps avoid some transport-related issues.

There is also a new option to **automatically cycle through providers** until a working one is found. This option automatically appears when a playback issue is detected.

Streaming now lets you delete the previous batch selection, and debrid downloading has been improved to handle more edge cases with providers like TorBox and Real-Debrid.

## [#](#v30)v3.0

Important

All built-in extensions have been removed. You will need to install the necessary extensions manually from external sources. [Refer to the getting started guide](/#2-add-extensions).

**WeebHub Denshi** is a new desktop client for WeebHub. It was built to replace **WeebHub Desktop** and is now available for Windows, macOS, and Linux.

Migrate to Denshi

If you were using WeebHub Desktop, you need to manually download WeebHub Denshi to upgrade. After that, you won't have to manually update it anymore.

Why? WeebHub Desktop was built using Tauri, a lightweight Rust-based framework for building cross-platform desktop applications. Tauri is great, but it's not a good fit for video-oriented applications. WeebHub Denshi is based on Electron, though heavier and more memory-intensive, it is much more stable and consistent.

### [#](#nakama)Nakama

Nakama is a new _experimental_ feature that allows communication between WeebHub instances, enabling features like:

*   **Library sharing**: Share your anime library with friends and let them stream it.
*   **Watch together**: Watch anime together with friends in real-time.

In the simplest terms, Nakama allows a host WeebHub instance to act as a media source or streaming server. Communication is done through HTTP requests from protected endpoints and WebSockets for real-time updates.

![Page](https://i.postimg.cc/JhkpkXXG/img-2025-07-04-20-47-15-2x.png)

  

Nakama requires the host WeebHub instance to be accessible over the internet, which can be achieved with multiple methods (like port forwarding, reverse proxy, or using a cloud server).

Plugins are a new type of extension that allow for more in-depth customization and allow addition of new features — all in JavaScript.

Here is a high overview of what they're capable of:

*   Create a tray icon and display dynamic content in the tray

*   Run commands, access the file system, create, read, edit files etc.
*   Communicate with AniList and other APIs
*   Fetch and store data
*   Manipulate the DOM
*   And more
