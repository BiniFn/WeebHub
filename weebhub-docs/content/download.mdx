# Download WeebHub

WeebHub is available for Windows, macOS, and Linux.

## Desktop Installers

You can download the latest installers from the GitHub Releases page:

[View Releases on GitHub →](https://github.com/BiniFn/WeebHub/releases)

### Windows
Download the `.exe` installer or the `.zip` archive from the latest release.

### macOS
Download the `.dmg` file. Remember to allow the app to run in System Settings > Security & Privacy.

### Linux
Download the `.AppImage` file, make it executable, and run it.

## Running Locally

If you prefer to run WeebHub from source, you can clone the repository and run it with Go:

```bash
git clone https://github.com/BiniFn/WeebHub.git
cd WeebHub
go run main.go
```

After starting the server, open your browser and navigate to:
`http://127.0.0.1:43211`
