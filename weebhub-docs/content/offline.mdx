# Offline mode[#](#offline-mode)

Offline mode allows you to use the main features of WeebHub without an internet connection or when AniList is down. It includes **metadata** and **images** for anime and manga, **progress tracking** and **list management**.

## [#](#1-choose-what-you-want-to-save)1\. Choose what you want to save

*   Go to the `Offline` page.
*   Click `Select media to save` and select the series you want to save for offline mode. Then, click `Save locally`.
*   Alternatively, you can automatically save all series you're watching/reading. Go to `Settings > App` and check `Save all currently watched/read media for offline use`.

## [#](#2-sync-local-data)2\. Sync local data

Click `Sync now`, then `Update local data` to start the syncing process. By default, this has to be done manually.

Automate this step

In `Settings > App` check `Automatically refresh local data` to automatically update your local data every 30 minutes.

## [#](#3-use-offline-mode)3\. Use offline mode

To enable offline mode, navigate to the offline page and click on `Enable offline mode`.

You can now use WeebHub and make local changes.

## [#](#4-going-back-online)4\. Going back online

*   Click on the offline icon in the sidebar, then confirm the action.
*   Go to the offline page and click `Sync now`, then `Upload local changes to AniList` to update your AniList collection with the changes you made offline.
