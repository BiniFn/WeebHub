## [#](#1-home-screen)1\. Home Screen

Ensure `Local anime + Streaming` is enabled in the home settings. This will make it so library items on the home screen (Continue Watching, Anime Library, ...) include non-downloaded episodes you're currently watching.

## [#](#2-add-extensions)2\. Add extensions

First, for torrent/debrid streaming, make sure you have at least one torrent provider extension installed. For online streaming, make sure you have at least one online streaming extension installed.
