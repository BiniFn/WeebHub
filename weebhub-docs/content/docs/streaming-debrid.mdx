# Debrid streaming[#](#debrid-streaming)

Copy Markdown

Debrid streaming is a feature that allows you to stream files from your debrid provider.

![Streaming](https://WeebHub.app/bucket/guides/img-20260507-162337-k4d15t0v--sq.webp)

## [#](#setup)Setup

1.  In `Settings > Debrid streaming`, choose a provider ([TorBox](https://torbox.app/) or [Real-Debrid](https://real-debrid.com/))
2.  Enter your API key
3.  If you're using an external player, make sure it is configured (follow the getting started guide).

## [#](#faq)FAQ

##### [#](#auto-select-issues)Auto-select issues

![Streaming](https://WeebHub.app/bucket/guides/img-2026-01-19-13-32-23.png)

Auto-select errors are not WeebHub-related bugs, it simply means your default torrent provider extensions (`Settings > Torrent Provider`) were not able to find any torrents for the episode you are trying to stream.

*   Make sure you have at least one torrent provider extension installed.
*   The extension might struggle to query the torrent provider accurately enough, select a torrent manually instead.
