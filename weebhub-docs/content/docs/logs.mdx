## [#](#issue-recorder)Issue Recorder

The Issue Recorder is a tool that allows you to record anonymized logs of the app and send them to the developer for troubleshooting.

How to use the issue recorder

Go to the settings page and click on `Record an issue`

![Image](https://i.postimg.cc/WbGrT0Vp/img-2025-02-08-11-32-55-2x.png)

A small window will appear, click on the `Start recording` button and recreate the issue you want to report. When you're done, click on the `Stop recording` button, download the file and send it to the developer.

![Page](https://WeebHub.app/bucket/guides/3_5-004.gif)

## [#](#log-files)Log files

How to find the log files.

Reminder

The default location of the data directory depends on your operating system. ("%APPDATA%\\Roaming\\WeebHub" or "%APPDATA%\\WeebHub" on Windows, "~/Library/Application Support/WeebHub" on macOS, etc.)

In the data directory

All logs are stored in the **WeebHub data directory**, under the `logs` folder.

![Image](https://files.catbox.moe/9nip1x.png)![Image](https://i.postimg.cc/fy1425Ny/data-dir-logs.jpg)

In the app

You can also access the logs from the app itself. Go the settings page and click on the `Logs` tab. The latest log file is displayed at the top.

![Image](https://files.catbox.moe/rlrgej.png)

## [#](#types-of-logs)Types of logs

Logs are categorized into two types: scanner logs and server logs.

Scanner logs

Scanner logs are created each time you **scan/refresh** your anime library.

![Image](https://i.postimg.cc/m2M2x16J/Clean-Shot-2024-10-26-at-14-00-21.png)

Server logs

Server logs are created each time you launch WeebHub and are continuously written to during the lifetime of the server.

![Image](https://i.postimg.cc/hjnJXbzk/Clean-Shot-2024-10-26-at-14-25-32.png)
