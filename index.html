Run WeebHub locally.

WeebHub by BiniFn is a local anime and manga media server with a browser app, Android browser access over Wi-Fi, Discord Rich Presence, and desktop release builds.

Read the docs Download options 
git clone https://github.com/BiniFn/WeebHub.git
cd WeebHub
go run main.go

Android browser

Open the local server from your phone on the same Wi-Fi.

Desktop apps

Windows, macOS, and Linux builds are published from GitHub Releases.
