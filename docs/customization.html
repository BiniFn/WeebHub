    #UI Customization#

    Copy Markdown

    ##Home Screen

    You can customize the home screen by adding and reordering items.

    ##Color scheme

    WeebHub allows you to customize the color scheme of the UI by setting custom colors.

    • Go to Settings > User interface and enable color settings
    • Set the background and accent colors to your liking. Be mindful that the background color should be a dark color for better readability.

    You can also choose between the predefined color swatches.

    ##Background and Banner

    WeebHub allows you to set a custom background image and banner.

    The images you want to use as banners or backgrounds should be placed in a directory which is configurable in your config.toml file. The default path of the asset directory is $SEANIME_DATA_DIR/assets.

    • Create a directory named assets in your WeebHub data directory.
    • Place your images in the assets directory
    • In the UI settings, set the image paths to the relative path of the image in the assets directory.

    ##Example

    📁 path/to/WeebHub/data/dir
    ├── config.toml
    ├── WeebHub.db
    └── 📁 assets               <- New
        ├── 🖼️ banner.jpg
        ├── 🖼️ background.gif
        └── 🖼️ banner-2.gif

    Then, set Background image path to background.gif in the UI settings.

    ##How to change the asset directory

    • Change the web.assetdir setting in your config.toml file to whatever you want, the path should be absolute. The default directory is $SEANIME_DATA_DIR/assets.

    ##Custom CSS

    • Go to Settings > User interface and enter your custom CSS under the Advanced dropdown.
