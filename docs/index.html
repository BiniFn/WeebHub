WeebHub docs

Everything here credits BiniFn / WeebHub. Use these commands to run the local web app and connect other devices.

Run Locally

git clone https://github.com/BiniFn/WeebHub.git
cd WeebHub
go run main.go

Then open http://127.0.0.1:43211.

Open From Android

Keep your computer and Android device on the same Wi-Fi. Start WeebHub so other devices can reach it:

go run main.go --host 0.0.0.0

Find your computer IP:

macOS: ipconfig getifaddr en0
Windows: ipconfig
Linux: hostname -I

On Android, open:

http://YOUR-COMPUTER-IP:43211

Discord Rich Presence

  1. Install the Discord desktop app and sign in.
  2. Keep Discord open in the background.
  3. Start WeebHub with go run main.go.
  4. Open http://127.0.0.1:43211.
  5. Go to Settings, then Discord, and turn on Rich Presence.
  6. Leave the GitHub repo button visible so Discord shows the WeebHub repo link.

GitHub Pages 404 Fix

If GitHub Pages shows “There is not a GitHub Pages site here,” open repository Settings, then Pages.

  • For the GitHub Actions workflow: set Source to Deploy from a branch, branch gh-pages, folder / root.
  • For this fallback site: set Source to Deploy from a branch, branch main, folder / root.

After saving, wait a minute and open https://binifn.github.io/WeebHub/.
