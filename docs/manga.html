    #Manga#

    Copy Markdown

    ##Add extensions

    Good to know

    The manga 'library' page and home items are based on what series you add to your lists.

    • Enable manga support in the settings if you haven't already
    • Navigate to the Manga page to see your manga lists. (Reading, Planning, Completed)
    • Find manga provider extensions

    ##Read chapters

    ##Refresh sources

    WeebHub will cache the chapters from online sources for a few days. Local sources are fetched once when the app is launched. Clicking Refresh sources will empty the cache and fetch the latest chapters for all manga entries you're currently reading.

    ##Fix incorrect matches

    If you notice that the chapters aren't correct or are not found, click Manual match to search and select the correct manga entry from the source. This works for both online and local sources.

    ##Download from online sources

    More on the offline feature.

    ##1. Add to the queue

    • Select the chapters you want to download
    • Click on the Download selected chapters button
    • This will add the chapters to the download queue

    Good to know

    The download process does not start automatically after adding chapters to the download queue. You need to start it manually.

    ##2. Download

    • Click on the Downloads button in top right corner to open the download drawer.
    • Click Start to start the download process, Stop to pause the download process, Clear all to remove all chapters from the download queue.

    Good to know

    The download queue will persist even if you restart the server.

    ##3. Downloaded chapters

    Scroll down to see the list of downloaded chapters.

    • You can delete downloaded chapters by selecting them and clicking on the Delete selected chapters button.
    • Note: If you want to delete ALL downloaded chapters regardless of the manga, simply delete the contents of the manga directory in your data directory.

    Location of downloaded chapters on disk

    The downloaded chapters will be saved in a directory that is configurable in your config.toml file (Default is $SEANIME_DATA_DIR/manga)

    Example

    path/to/data/dir
└── 📁 manga
    ├── 📁 online_150378_to8mbIMM_1
    ├── 📁 online_150378_oWWoK_2
    └── ...

    Note: The directory structure is not human-readable and is not meant to be accessed directly. You should use the web interface to manage downloaded chapters. If you want a more readable and reusable directory, opt for local sources.

    ##Troubleshooting

    WeebHub will automatically detect errors during the download process (e.g. network issues, undownloaded pages, etc.) and will mark the chapter as errored. When that happens, you can click on Reset errored chapters, then you can start the download process again.

    • If the download process won't start, try restarting the server.
    • Read the terminal logs for more information about the status of the download process and any errors that may have occurred.

    ##Local sources

    WeebHub supports local file sources (ZIP, CBZ, RAR, .jpg, .png). Add the files to the local manga directory and select Local as the source on the manga page.

    The default location of the manga directory is $SEANIME_DATA_DIR/manga-local. You can change it in the manga settings.

    Note: You need to refresh the sources each time you add or remove files from the library folder.

    ##Folder structure

    Good to know

    There is no strict naming convention, WeebHub uses a parser that expects simple use cases.

    Archive

    path/to/data/dir
└── 📁 Series
        ├── Chapter 1.cbz
        ├── Chapter 2.cbz
        └── ...

    Image

    path/to/data/dir
└── 📁 Series
        └── 📁 Chapter 1
                ├── 01.jpg
                ├── 02.jpg
                └── ...
