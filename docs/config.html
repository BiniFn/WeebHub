    #Config#

    Copy Markdown

    ##Data directory

    The data directory contains all files WeebHub uses to function. It represents a single instance of WeebHub. It is automatically created the first time you launch WeebHub.

    The default location of this directory varies depending on your operating system and environment variables. (%APPDATA%\WeebHub on Windows, ~/Library/Application Support/WeebHub on macOS, etc.)

    You can open it from the in-app settings.

    ##config.toml

    WeebHub uses a config.toml file to store its configuration. This file is located in the data directory.

    Info

    A restart is required for changes to take effect.

    ## The current version of WeebHub (DO NOT CHANGE)
version = ''

[cache]
## The directory where cached data is stored
dir = '$SEANIME_DATA_DIR/cache'
## The directory where transcode video segments are stored
transcodedir = '$SEANIME_DATA_DIR/cache/transcode'

[database]
## The name of the database
name = 'WeebHub'

[logs]
## The directory where logs are stored
dir = '$SEANIME_DATA_DIR/logs'

[manga]
## The directory where manga chapters are downloaded
downloaddir = '$SEANIME_DATA_DIR/manga'
## The directory used by the local manga provider
localdir = '$SEANIME_DATA_DIR/manga-local'

[offline]
## The directory where offline assets are downloaded
assetdir = '$SEANIME_DATA_DIR/offline/assets'
## The directory where the offline database is stored
dir = '$SEANIME_DATA_DIR/offline'

[server]
## The host to bind the server to
host = '127.0.0.1'
## Whether the server should run in offline mode
offline = false
## The port to bind the server to
port = 43211
## Password for authenticated remote access
password = ''
## Optional passwordless exceptions for specific public hosts or origins
accessAllowlist = []
## Reverse proxies allowed to supply X-Forwarded-* headers
trustedProxies = []
## Canonical public URL used for proxy-aware HTTPS detection
externalURL = ''
## Passwordless boundary mode: '', 'hardened', 'lax', or 'strict'
secureMode = ''
## Whether SEANIME_WORKING_DIR should be the binary path (true) or the system's working directory (false)
usebinarypath = true

[web]
## The directory where custom web assets like background images are stored
assetdir = '$SEANIME_DATA_DIR/assets'

    ##Server password

    If your WeebHub server is reachable from outside your machine, setting server.password is required. This enables normal authenticated remote access and is the safest default for VPS and reverse-proxy setups.

    Add the following line to the [server] section of your config.toml file:

    config.toml

    [server]
password = 'your_password_here'

    ##Security

    ##Secure mode

    WeebHub supports passwordless access for local use, but the exact boundary depends on server.secureMode. Local desktop use, localhost use, and Denshi are expected to keep working in the default configuration.

    Setting

    Purpose

    Typical use

    server.secureMode = ''

    Keeps the baseline passwordless boundary.

    Default behavior.

    server.secureMode = 'hardened'

    Restricts passwordless access to loopback and localhost.

    Use when passwordless access should stay local-only.

    server.secureMode = 'lax'

    Disables the baseline passwordless boundary.

    Use only if you intentionally want the broadest passwordless behavior.

    server.secureMode = 'strict'

    Includes the hardened boundary and adds extra trusted-local-only restrictions for sensitive actions.

    Use for tighter host-level protections.

    ##Default mode

    With secureMode = '', passwordless /api/** and /events requests are allowed when the request host is localhost, loopback, or a literal private-LAN address. Browser requests with Origin or Referer still need to come from a trusted local-looking origin or an allowlisted origin, and cross-site requests without usable origin metadata are denied.

    Practical effect:

    • http://127.0.0.1:43211 works
    • http://192.168.1.10:43211 also works in passwordless mode
    • Passwordless public hostnames do not work unless they are allowlisted or secureMode = 'lax' is used

    Warning

    The default passwordless mode is convenient, but it is inherently insecure. For hosted deployments, server.password is required.

    ##Hardened mode

    With secureMode = 'hardened', passwordless /api/** and /events only auto-trust loopback and localhost hosts. Literal private-LAN hosts and origins are no longer auto-trusted, while Denshi's origin remains trusted when the server is local.

    Practical effect:

    • http://127.0.0.1:43211 works
    • http://192.168.1.10:43211 does not work in passwordless mode
    • Passwordless public access can still work if the public host or origin is explicitly allowlisted

    ##Strict mode

    Warning

    Strict mode is very restrictive and may cause some features to not work as expected.

    secureMode = 'strict' includes the hardened passwordless boundary and adds extra trusted-local-only restrictions for sensitive actions. This includes areas such as extension management, selected settings and root-path mutations, and some plugin APIs.

    This gives stronger protection, but it does not replace the security benefits of using server.password for authenticated access, and it may cause some features to not work in passwordless mode.

    Example:

    • Plugins no longer have access to system bindings, even with permissions
    • All download operations are now path-restricted to specific directories
    • You cannot update certain settings like application paths, unless you are on a trusted local host (e.g. ssh into the server)

    ##accessAllowlist

    Use server.accessAllowlist when you intentionally want passwordless exceptions for specific public hosts or origins (which is a rare case). It opens the passwordless /api/** and /events boundary for the hosts or origins you list.

    config.toml

    [server]
accessAllowlist = ['https://demo.example.com']

    Info

    server.accessAllowlist does not make a remote caller trusted local. In strict mode, sensitive operations still require a trusted local boundary.

    ##Reverse proxies

    If WeebHub is running behind Nginx, Caddy, Traefik, or another reverse proxy, configure server.trustedProxies and usually server.externalURL.

    Setting

    Purpose

    Typical use

    server.trustedProxies

    Declares which proxies may supply X-Forwarded-* headers.

    Required when WeebHub should trust forwarded client IP, host, or protocol.

    server.externalURL

    Canonical public URL used for proxy-aware HTTPS detection and request normalization.

    Set this when WeebHub is served behind HTTPS.

    If you rely on forwarded headers but do not configure server.trustedProxies, WeebHub treats the direct connection as authoritative. If the public site is HTTPS, set server.externalURL so WeebHub can normalize requests correctly.

    ##Run multiple instances

    Running multiple instances of WeebHub is as simple as launching the executable with a different data directory. You can do this by setting the SEANIME_DATA_DIR environment variable or using the --datadir flag.

    This is not possible for the desktop app.

    Example

    ## Run a second instance
WeebHub.exe --datadir="C:\Users\nobody\Documents\WeebHubData"

    Example

    ## Run a second instance
./WeebHub --datadir="/Users/nobody/Documents/WeebHubData"

    Info

    Give each instance a different port in their respective 'config.toml' file if you plan on running them simultaneously.

    ##DNS over HTTPS

    You can use DNS over HTTPS to bypass potential ISP blocks. To do this, add the following to your config.toml file under the [server] section:

    config.toml

    [server]
dohurl="https://cloudflare-dns.com/dns-query{?dns}"

    ##TLS

    config.toml

    [server.tls]
enabled = true

    ##Environment variables

    Here are the environment variables that WeebHub uses:

    ##SEANIME_DATA_DIR

    The path to the data directory. Launch WeebHub with this environment variable to set the data directory.

    ##SEANIME_SERVER_HOST

    Launch WeebHub with this environment variable to set the server host. This will override the default host set in the config.toml file when launching WeebHub for the first time.

    ##SEANIME_SERVER_PORT

    Launch WeebHub with this environment variable to set the server port. This will override the default port set in the config.toml file when launching WeebHub for the first time.

    ##SEANIME_WORKING_DIR

    If usebinarypath is set to true, this variable will be set to the directory where the executable is located, otherwise it will be set to whatever the system's working directory for the executable is.
