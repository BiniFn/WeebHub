    ##v3.8

    ##UI and Performance Improvements

    • WeebHub Denshi now uses native View Transitions for smoother navigation and a more polished feel.
    • Animations have also been updated across the app to be more consistent in speed and feel snapper.
    • Media entry headers have been slightly redesigned to be more compact and less visually noisy.
    • Route preloading is now enabled by default and configurable in the settings.
    • Various optimizations have been made to increase loading speed for media pages. In addition to that, route preloading will make navigating to some media pages feel almost instant.

    ##Improved Torrent Search

    Torrent search can now query many providers at once, which makes it easier to compare results without having to switch between providers manually. This should make discovery faster, especially when availability differs across providers.

    ##Updated Subtitle Translator

    The subtitle translator now supports OpenAI-compatible local LLMs, making it possible to use self-hosted models instead of relying only on remote services. Language selection has also been fixed so translation setup behaves more consistently.

    VideoCore (the in-app video player) will also now automatically import local subtitle files from the same directory as the video file. For external player links, a new {subtitleUrl} placeholder has been added to make passing local subtitle files easier.

    ##Denshi Window State

    WeebHub Denshi now remembers window position and size between sessions, so the app reopens where you left it.

    ##Hide Anime Spoilers

    The 'Hide Anime Spoilers' plugin has been implemented natively for better performance. This will hide episode titles, descriptions, and thumbnails until you watch the episode. There is also a new /spoilers command in the Command Palette that lets you toggle spoilers on or off for an individual title for convenience.

    ##Extension Improvements

    Many improvements have been made to the extension system, including more APIs for deeper integrations and better security controls. Extensions can now be disabled directly, which is useful when you need to quickly disable a misbehaving extension without uninstalling it.

    Plugins also gained more APIs, including ctx.settings to securely manage app settings, ctx.auth to securely manage authentication, and ctx.extensions to securely manage other extensions. To complement that, there is a new Extension Secure Mode setting that shows a prompt when an extension attempts a sensitive action.

    ##Online Streaming Improvements

    Online streaming now uses a new HTTP/1-based video proxy, which helps avoid some transport-related issues.

    There is also a new option to automatically cycle through providers until a working one is found. This option automatically appears when a playback issue is detected.

    Streaming now lets you delete the previous batch selection, and debrid downloading has been improved to handle more edge cases with providers like TorBox and Real-Debrid.

    ##Bug Fixes & Other Improvements

    • qBittorrent: Fixed support for 5.2.x
    • Cache mode: Queued updates are now deleted on manual mutation
    • Online streaming: Fixed video source selection
    • Online streaming: Fixed occasional HTTP/2-related errors
    • Plugins: Faster reads for $storage and $store
    • UI: Fixed some UI issues
    • Auto Downloader: Fixed handling of debrid downloads
    • Core: Fixed handling of stale cookies
    • Updated Go to 1.26.2

    ##v3.7

    ##Security Improvements

    Security has been tightened across the app and server, with a stronger default posture and more explicit controls for deployments.

    Breaking Change

    Passwordless access is now local-only, meaning you will need to set a password for hosted deployments if you haven't already.

    • Passwordless access is now local-only by default (future updates will require a password to enable network access)
    • Electron renderer security has been improved, and additional checks have been added around client identity and the macOS server-side updater
    • You can also now enable server.securemode = "strict", which reduces the attack surface for public deployments, but disables some features and plugin APIs
    • Added server.accessAllowlist, server.trustedProxies, and server.externalUrl as options

    ##Search and Tags

    Search now supports tags, making it easier to filter and find content using them. Global search also no longer filters out adult entries, which makes results more consistent with the source data.

    ##New Plugin APIs

    Plugins gained a new set of APIs and hooks, especially around playback, scanning, torrent workflows, and automation. This should make it easier to build deeper integrations without relying on workarounds.

    • Added VideoCore play methods and skip data manipulation
    • Added an API to register an episode tab
    • Added hooks for Auto Downloader and torrent search
    • Added API methods for Playback, Scanner, Debrid, Torrent Streaming, Torrent Search, and Auto-select

    ##Other Improvements

    • Windows now uses the user-default explorer application to open folders
    • Text inputs on WeebHub Denshi support a right-click context menu
    • Subtitle parsing for local files is faster in the in-app player
    • The Denshi player now enters fullscreen with a double click instead of a double right-click.

    Internally, Denshi startup no longer depends on a websocket connection, which should make the app more resilient during launch and reconnection scenarios.     ##v3.5

    ##New Library Scanner

    The library scanner has been completely rewritten with context-aware matching that goes beyond simple fuzzy matching algorithms. It provides generally more accurate results, especially for complex naming conventions and edge cases that previously required manual intervention.

    Key Improvements:

    • Context-Aware Matching: Handles title variations with smarter parsing and comparison logic
    • Enhanced Accuracy: Better recognition of multi-season anime, movies, and specials
    • Anime Offline Database: Leverages the Anime Offline Database for better accuracy when matching without AniList collection
    • Custom Rules: Configure matching and hydration behavior to fit your library structure

    ##Enhanced Issue Recorder

    The Issue Recorder now captures UI interactions, making it much easier to reproduce and diagnose problems.

    New Features:

    • Session Replay: Records UI interactions for accurate issue reproduction
    • Screenshots: Attach images directly to your recordings
    • Notes: Add descriptions to help identify problems
    • Enhanced analysis: Internal tools now include session replays for faster debugging

    The built-in WeebHub media player (VideoCore) received some updates.

    New Features:

    • Transcoding/Direct Play: VideoCore is now used for transcoding and direct play playback
    • Stats for nerds: Press Z to view detailed playback information including file path, codecs, and performance metrics
    • Character lookup: Press H to quickly look up characters while watching
    • Updated subtitle renderer: Upgraded LibASS renderer for more performant subtitle rendering

    • Theming: New toggle to restore blur effects in the UI

    ##v3.0

    Important

    All built-in extensions have been removed. You will need to install the necessary extensions manually from external sources. Refer to the getting started guide.

    WeebHub Denshi is a new desktop client for WeebHub. It was built to replace WeebHub Desktop and is now available for Windows, macOS, and Linux.

    Migrate to Denshi

    If you were using WeebHub Desktop, you need to manually download WeebHub Denshi to upgrade. After that, you won't have to manually update it anymore.

    Why? WeebHub Desktop was built using Tauri, a lightweight Rust-based framework for building cross-platform desktop applications. Tauri is great, but it's not a good fit for video-oriented applications. WeebHub Denshi is based on Electron, though heavier and more memory-intensive, it is much more stable and consistent.

    ##Native Media Player

    WeebHub Denshi comes with an all-new built-in media player that supports more codecs than web browsers, SSA/ASS subtitles, and even GPU-based sharpening with Anime4K.

    Good to know: The built-in media player is still a work in progress. More features will be added in the future.

    • Full support for Nakama
    • Subtitle delay
    • Custom shaders

    ##Home Screen

    The home screen replaces the 'My Library' page. It is now a fully customizable screen that allows you to display your media (anime & manga) and more items in a variety of ways.

    ##Custom Sources

    WeebHub is no longer limited to AniList. You can now create your own custom source extensions (in JavaScript) for adding anime and manga series to WeebHub and share them. Refer to the extension documentation for more information.

    ##Library Explorer

    The library explorer is a new feature that allows you to browse your local anime library and manage your media files. You can now quickly and easily identify and solve mismatches, bulk edit metadata and file names, and more.

    ##Playlists

    The playlist system has been completely rewritten. You can now seamlessly transition between different playback methods. Playlists now work with external player links on mobile. It is also now easier to add episodes to playlists from the right-click context menu.

    The native MPV and IINA playlist feature is now leveraged for downloaded media files, providing a truly seamless transition between episodes.

    ##Improvements

    • New cache layer for zero downtime
      • All requests are now automatically cached to disk
      • WeebHub will keep working as usual when AniList is temporarily down
    • Unmatched files: Integrated search & preview for faster matching
    • Torrent/Debrid streaming improvements:
      • Auto play next episode now works when episode file is selected manually
      • Files are now selected automatically based on index after the first one is selected manually
      • Manual file selection is now easier with a redesigned interface
    • Torrent client: Select files to download from batches
    • Online Streaming: Previous/Next button
    • Various bug fixes

    ##v2.9

    ##Nakama

    Nakama is a new experimental feature that allows communication between WeebHub instances, enabling features like:

    • Library sharing: Share your anime library with friends and let them stream it.
    • Watch together: Watch anime together with friends in real-time.

    In the simplest terms, Nakama allows a host WeebHub instance to act as a media source or streaming server. Communication is done through HTTP requests from protected endpoints and WebSockets for real-time updates.

    Nakama requires the host WeebHub instance to be accessible over the internet, which can be achieved with multiple methods (like port forwarding, reverse proxy, or using a cloud server).

    ##Plugins

    Plugins are a new type of extension that allow for more in-depth customization and allow addition of new features — all in JavaScript.

    Here is a high overview of what they're capable of:

    • Create a tray icon and display dynamic content in the tray
    • Add buttons, context menu items, dropdown items to specific places
    • Create a dynamic command palette
    • Register hooks to modify server-side behavior
    • Run commands, access the file system, create, read, edit files etc.
    • Communicate with AniList and other APIs
    • Fetch and store data
    • Manipulate the DOM
    • And more

    There is a new documentation website for plugins that you can check out to get started on creating your own.
