    #Built-in Player#

    Copy Markdown

    ##Overview

    WeebHub features a powerful built-in media player with advanced subtitle rendering, customizable keyboard shortcuts, and many quality-of-life features for watching anime.

    Info

    This guide is not for the Transcoding & Direct Play Built-in Player.

    ##Key Features

    • Advanced Subtitle Support - High-quality subtitle rendering with ASS format support
    • Anime4K Support - Real-time sharpening using Anime4K
    • Subtitle Translation - Real-time subtitle translation using DeepL or OpenAI
    • Customizable Keyboard Shortcuts - Remap all player controls to your preference
    • Screenshot Capture - Take screenshots of the current frame
    • Picture-in-Picture - Watch in a floating window while multitasking
    • Multiple Audio/Subtitle Tracks - Easy cycling between available tracks

    ##Keyboard Shortcuts

    All keyboard shortcuts are fully customizable.

    1. Open player preferences
    2. Go to the "Keyboard Shortcuts" tab
    3. Click on a shortcut button to record a new key
    4. Press the desired key on your keyboard
    5. Adjust the value for actions with numeric parameters (seek duration, volume increment, etc.)

    ##Subtitles

    ##Preferred Languages

    Set your preferred subtitle and audio languages to have them automatically selected when available:

    • Preferred Subtitle Language - e.g., eng,jpn (comma-separated, in order of preference)
    • Preferred Audio Language - e.g., jpn,eng,kor (comma-separated, in order of preference)

    ##Ignored Subtitle Names

    Specify subtitle track names to ignore during automatic selection. For example, enter sign & songs to avoid automatically selecting sign/song subtitle tracks when your preferred language is available.

    ##Subtitle Rendering

    ##SSA/ASS

    By default, WeebHub renders subtitles using the SSA/ASS1 format. For online streaming, this is done by converting all non-ASS subtitle tracks to SSA.

    1 ASS (Advanced Sub Station Alpha) is a subtitle format typically used by anime fansubs which supports advanced styling and effects.

    Pitfall

    The SSA/ASS renderer uses a font that does not support all languages' characters by default. If your language is not rendering correctly, you may need to add custom fonts or disable this feature. Check out the guides below.

    ##Adding Custom Fonts

    If subtitles in your language are not rendering correctly (showing boxes or missing characters), you need to add the appropriate font files to WeebHub's data directory.

    Step-by-step guide:

    1. Download the required fonts

      • For other languages: Visit Google Webfonts Helper (Noto Sans fonts are recommended)
      • Download the font package and extract the .woff2 file

    2. Extract and copy font files

    • Navigate to WeebHub's data directory
    • Copy the font file to the assets folder
    • Open player menu, enable Subtitle Styles and open the Font submenu
    • Enter the file name in the player preferences

    ##Use Native Format

    • Open player preferences and go to the Subtitles tab
    • Disable Convert Soft Subs to ASS and WeebHub will render the actual subtitle format (SRT, VTT, etc.) using another renderer.

    Info

    This option is only available for web players (online streaming)

    ##Subtitle Translation

    Warning

    This feature is in alpha and may not work as expected.

    The built-in player can automatically translate subtitles to your preferred language in real-time.

    ##Setup
    1. Open player preferences and go to the Translation tab
    2. Turn on Enable Translation
    3. Choose your translation provider:
      • DeepL - High-quality translation (limited language support)
      • OpenAI - Wider language support
    4. Select your target language
    5. Enter your API key for the chosen provider
    6. Click "Save"

    Note: Reloading the player is required when switching languages or changing the API key.

    ##Troubleshooting

    ##Subtitles not displaying correctly

    • If you're noticing that your language isn't rendering correctly, try adding a custom font or disabling "Convert Soft Subs to ASS" (web players only).
    • Ensure the subtitle track is enabled (cycle through tracks with the subtitle key)

    ##Translation not working

    • Verify your API key is correct
    • Reload the player after changing translation settings
    • Check that your target language is supported by your chosen provider

    ##Keyboard shortcuts not working

    • Click on the video player to ensure it has focus
    • Check if the shortcuts are being captured by another application
    • Try resetting shortcuts to defaults in the preferences
