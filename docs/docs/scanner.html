    ##Scanner

    Copy Markdown

    The scanner is the core component of WeebHub that traverses your local directories, parses file paths, and matches them to your AniList collection. It is designed to be flexible and work with various file naming conventions.

    ##How it works

    1. Reading: The scanner goes through through your library paths.
    2. Parsing: It parses file paths to extract the title, season, and episode number. It also normalizes titles to facilitate matching.
    3. Matching: It tries to find a matching media in your AniList collection (or from external sources if specified) based on the parsed metadata.
    4. Hydration: Once a match is found, the scanner updates the file's metadata in WeebHub (e.g., episode number, type) based on the AniDB entry of the media.

    ##Matching

    The scanner works best when your files follow standard naming conventions. It considers both the file name and the folder structure.

    ##Series

    File names should include the season number OR be located in a folder with the season number (e.g., Season 1, S1, 2nd Season).

    Season

    path/to/local/library
└── 📁 Bungou Stray Dogs
    ├── [WeebHub] Bungou Stray Dogs - S05E01.mkv <- ✅ Season 5
    ├── [WeebHub] Bungou Stray Dogs - S05E02.mkv
    └── ...

    Season

    path/to/local/library
└── 📁 [WeebHub] Bungou Stray Dogs 5th Season (Batch) [BDRIP 1920x1080] <- ✅ Season 5
    ├── [WeebHub] Bungou Stray Dogs - 01.mkv
    ├── [WeebHub] Bungou Stray Dogs - 02.mkv
    └── ...

    Absolute

    path/to/local/library
└── 📁 [WeebHub] Bungou Stray Dogs (Batch) [BDRIP 1920x1080]
    ├── [WeebHub] Bungou Stray Dogs - 49.mkv                     <- ✅ Season 5
    ├── [WeebHub] Bungou Stray Dogs - 50.mkv                     <- ✅ Season 5
    └── ...

    Multiple

    path/to/local/library
└── 📁 [WeebHub] Bungou Stray Dogs (Batch) [DUAL][BDRIP 1920x1080]
    ├── 📁 Season 1                                                 <- ✅ Season 1
    │   ├── Bungou Stray Dogs - 05.mkv
    │   └── ...
    ├── 📁 Season 2                                                 <- ✅ Season 2
    │   ├── Bungou Stray Dogs - 05.mkv
    │   └── ...
    ├── 📁 Season 3                                                 <- ✅ Season 3
        ├── Bungou Stray Dogs - 05.mkv
        └── ...

    Multiple

    path/to/local/library
└── 📁 [WeebHub] Jujutsu Kaisen Season 1-2 (Batch) [DUAL][BDRIP 1920x1080]
    ├── Jujutsu Kaisen - 01.mkv                                 <- ✅ Season 1
    ├── Jujutsu Kaisen - 02.mkv                                 <- ✅ Season 1
    ├── ...
    ├── Jujutsu Kaisen - 25.mkv                                 <- ✅ Season 2
    ├── Jujutsu Kaisen - S02E02.mkv                             <- ✅ Season 2
    └── ...

    ##Movies

    Movies should be placed in their own folder, preferably near the root of the library. Avoid mixing movie files with series episodes in the same folder.

    🚫

    path/to/local/library
└── 📁 Neon Genesis Evangelion Complete Series
    ├── Neon Genesis Evangelion 01.mkv
    ├── Neon Genesis Evangelion 02.mkv
    ├── ...
    └── 📁 Rebuild Of Evangelion
        ├── Evangelion: 1.0 You Are (Not) Alone.mkv
        └── Evangelion: 2.0 You Can (Not) Advance.mkv

    ✅

    path/to/local/library
├── 📁 Neon Genesis Evangelion Complete Series
│ ├── Neon Genesis Evangelion 01.mkv
│ ├── Neon Genesis Evangelion 02.mkv
│ └── ...
├── 📁 Evangelion: 1.0 You Are (Not) Alone
│   └── Evangelion: 1.0 You Are (Not) Alone.mkv
└── 📁 Evangelion: 2.0 You Can (Not) Advance
    └── Evangelion: 2.0 You Can (Not) Advance.mkv

    ##Specials

    Specials are episodes that are not part of the main series (e.g. OVAs, NCs). WeebHub will parse them using specific patterns so that they do not interfere with main series progress.

    Files should be named as follows:

    Anime S00E01.mkv
Anime 00x01.mkv
Anime SP01.mkv
Anime Special 01.mkv

    Info

    If the special has its own entry on AniList, it should be placed in its own folder to ensure it is matched to that specific entry.

    ##Episode 0

    Sometimes AniList might include "Episode 0" as part of the main episode count (e.g. Mushoku Tensei II). In such cases, ensure that your library includes that special with the episode number 0.

    path/to/local/library
└── 📁 [WeebHub] Mushoku Tensei II Isekai Ittara Honki Dasu
    ├── [WeebHub] Mushoku Tensei S2 - 00 (1080p).mkv <- Episode 0
    ├── [WeebHub] Mushoku Tensei S2 - 01 (1080p).mkv
    └── ...

    ##Episode numbers

    WeebHub parses episode numbers from file names. The following examples show the correct ways episode numbers should be formatted.

    File

    Jujutsu Kaisen S02E05.mkv
Jujutsu Kaisen 05.mkv
Jujutsu Kaisen 05v2.mkv
Jujutsu Kaisen 05'.mkv
Jujutsu Kaisen 05.2.mkv
Jujutsu Kaisen 02x05.mkv
Jujutsu Kaisen S2 - 05.mkv
Jujutsu Kaisen S2_5.mkv
Jujutsu Kaisen 05 Episode title.mkv
Jujutsu Kaisen 2 - E05.mkv
Jujutsu Kaisen 2 - 05 - Episode title.mkv
Jujutsu Kaisen - S0205 - Episode title.mkv
S02E05 - Episode title.mkv

    Avoid the following patterns as they will be ignored or misidentified:

    Incorrect

    Jujutsu Kaisen 5.mkv              <- (Single digit) Will be IGNORED, rename to "05"
Jujutsu Kaisen 2 05.mkv           <- Will be IGNORED
Jujutsu Kaisen 1-5.mkv            <- Considered a range
Jujutsu Kaisen S2-5.mkv           <- Considered a range
Jujutsu Kaisen 5_2.mkv            <- Equivalent to S05E02, avoid versioning with "_"
Jujutsu Kaisen 05x02.mkv          <- Equivalent to S05E02, avoid versioning with "x"

    ##Troubleshooting matches

    If files are not being matched correctly, check the Scan Summary after a scan. It provides details on why certain files were not matched.

    Common reasons for mismatches:

    • Missing from AniList: You have not added the anime to your AniList account yet.
    • Title mismatch: The file or folder name is not similar enough to the anime titles listed on AniList.
    • Ambiguous season: The scanner cannot accurately determine the season of the episode (e.g., file denotes "Season 1" but AniList has no seasons).
    • Special episode: The scanner believes the episode is not part of the main series while it should be.

    ##Solutions

    • Add the anime to your AniList planning list.
    • Manually configure the scanner using Matching Rules or Resolution Rules.
    • Rename the file or folder to match the AniList title more closely.

    ##Metadata Hydration

    After a file is matched to a media (AniList entry), the scanner performs hydration. This step is responsible for assigning the correct metadata to the file, using the file's parsed data and the media's information.

    The hydrator assigns the following metadata:

    • Episode number: The relative episode number (e.g., 1, 2, 3).
    • AniDB episode: A string identifier used for tracking (e.g., 1, S1, OP1).
    • Type: The type of file (Main, Special, NC).

    ##Process

    The hydrator follows a specific logic (in order) to determine this metadata:

    1. Custom rules: It first checks if any Hydration Rules (defined in settings) apply to the file. If so, it uses the rule's output.
    2. NC/Specials detection: It checks if the filename indicates a Creditless (NC) video or a Special (OVA, OAD).
    • If detected as NC (e.g., "OP1", "ED"), it is marked as NC.
    • If detected as Special (e.g., "OVA"), it is marked as Special and assigned an episode number (usually 1 unless specified otherwise).
    1. Movies: If the matched media is a Movie, the file is automatically assigned Episode 1.
    2. Episode normalization:
    • If the file has a standard number (e.g., 05) and it fits within the media's episode count, it is assigned that number.
    • Absolute numbering: If the file uses an absolute episode number (e.g., 26) but the media is a sequel (e.g., "Season 2" which starts after ep 25), the hydrator will attempt to "normalize" it. It checks the media's relations (prequels) to subtract the previous episode counts.
    • Example: File Anime - 26.mkv matched to Anime Season 2 (where S1 has 25 eps) -> Hydrated as Episode 1.

    ##Examples

    Absolute numbering

    Files that follow a continuous episode count across seasons can be normalized if the media relations are correct.

    • File: Anime - 26.mkv
    • Matched Media: Anime Season 2 (Season 1 had 25 episodes)
    • Result: Episode 1

    Movies

    Movies are always hydrated as Episode 1.

    • File: Movie Title.mkv
    • Matched Media: Movie Title (Format: Movie)
    • Result: Episode 1

    Specials

    Files with specific keywords are hydrated as specials.

    • File: Anime - OVA.mkv
    • Matched Media: Anime Season 1
    • Result: Special 1 (AniDB: S1)

    NC (Creditless)

    Creditless openings and endings are identified by keywords like OP, ED, NC.

    • File: Anime - OP1.mkv
    • Matched Media: Anime Season 1
    • Result: NC (Opening 1)

    Episode 0

    Episode 0 is preserved (often a special/prologue).

    • File: Anime - 00.mkv
    • Matched Media: Anime Season 1
    • Result: Episode 0 (AniDB: S1)

    ##Configuration

    You can customize the scanner behavior in Settings > Local Anime Library, under the Advanced tab.

    ##Matching rules

    Matching rules rely on Regex to force the scanner to match specific file paths to a specific AniList media ID. This is useful when the auto-matcher consistently fails for a specific series.

    • path: The regex pattern (Go flavor) to match against the file paths.
    • mediaId: The AniList media ID to match against.
    {
  "matching": {
    "rules": [
      {
        "pattern": "Jujutsu Kaisen",
        "mediaId": 12345
      }
    ]
  }
}

    ##Hydration rules

    Hydration rules allow you to assign metadata (episode number, type) to files using Regex, overriding the defaults.

    • mediaId: The AniList media ID to apply this rule to (can use pattern instead).
    • pattern: The regex pattern (Go flavor) to apply this rule to (can use mediaId instead).
    • files: A list of rules to parse the episode information.
    {
  "hydration": {
    "rules": [
      {
        "mediaId": 12345,
        "pattern": "",
        "files": [
          {
            "filename": "Mob Psycho - S01E(\\d+) - (.*)$",
            "isRegex": true,
            "episode": "$1",
            "aniDbEpisode": "$1",
            "type": "main"
          },
          {
            "filename": "Mob Psycho - NC(OP|ED)(\\d+)$",
            "isRegex": true,
            "episode": "$1",
            "type": "nc"
          },
          {
            "filename": "Mob Psycho - Other.mkv",
            "type": "nc"
          }
        ]
      }
    ]
  }
}

    ##Verbose logging

    Enable verbose logging to see detailed information about the scanning process in the logs.

    {
  "logs": {
    "verbose": true
  }
