    #Comparison#

    Copy Markdown

    This comparison table is meant to give a general overview of how WeebHub's features compare to other software in the anime tracking and streaming space. It is based on online research and documentation and may not be totally accurate or up-to-date. Feel free to open a GitHub issue if you notice any inaccuracies or have suggestions for improvement.

    • ✅ 1st-class, built-in, and ready to use with no extra steps
    • 🟢 Supported, but comparatively limited in scope or functionality
    • 🟡 Supported, but as an unofficial 3rd party or community library/contribution
    • 🔶 Supported, not 1st-class or requires some extra steps
    • 🛑 Not officially supported or documented.
    • ✖️ Not supported and not a focus, or not applicable

    ##Local Anime Library

    Local Library: Abitrary collection of media files from local sources that are recognized by the app and matched to anime entries.
    File Structure: How local media files must be organized on disk for the app to recognize them. Flexible (arbitrary nesting), Strict (specific naming or structure required).
    Scanner: Traversal of a user-defined directory to parse arbitrary file names and folder hierarchy and match files to anime entries.
    Manual Matching: Manually resolving or overriding which anime/episode a local file is matched to.

    1 WeebHub uses the Habari filename parser and a configurable scanner with context-aware matching. Supports title variation matching and folder hierarchy analysis.

    2 Jellyfin relies on community plugins (e.g., Shokofin) for anime-specific file matching. Without these, it uses generic TVDB/TMDB naming conventions, which is usually poor for anime.

    3 Taiga uses the Anitomy filename parser for filename analysis, similar level to WeebHub's filename parsing.

    4 Hayase does not scan arbitrary file directories. Its library is built by importing torrents/magnets, which populates an internal torrent metadata cache.

    5 Taiga allows users to manually resolve unrecognized files by adding "alternative titles" or using the "Now Playing" identification feature.

    6 Shiru builds its library from a torrent metadata cache rather than user-defined directory layout.
